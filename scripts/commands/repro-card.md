# /repro-card

> Generate a fresh data card or environment card from raw material,
> inject auto-numbered references to the underlying files, and validate
> that every magic number cited in the card exists in the source.

## Usage

```
/repro-card data
/repro-card env
/repro-card data --for <run_id>
/repro-card env --for <run_id>
/repro-card data --from <path/to/dataset_dir>
/repro-card env --from <path/to/run_dir>
/repro-card help
```

## 4-step flow

| Step | Reads | Writes |
|---|---|---|
| **1. Inspect** | raw data dir or run dir | file list + sizes + checksums |
| **2. Render** | `templates/data_card.md` or `templates/environment_card.md` + inspected facts | new card |
| **3. Auto line matrix** | new card + source files | injects `Line X-Y` markers into each "source:" link |
| **4. Grep validation** | every magic number in the card | verifies each `N` appears in source files via `grep -nF` |

## Auto line matrix

For every "source:" link, the card includes the **line range** that
backs the claim. Example:

```markdown
- **source:** `data/data_hashes.json` Lines 12-87
```

This is generated by walking the source file once and locating the
relevant row(s). The range is then verified against the actual line
content in step 4.

## Grep validation

For each numeric value (e.g., `73.2`, `0.5`, `1e-6`), the command
runs `grep -nF "<value>"` over the cited source files. If the value
does not appear, the card is rejected with:

```
[repro-card] grep FAIL: value=73.2 not found in raw_metrics.json
```

## Output

```
[repro-card] step 1/4 inspect ................. 18 files, 4.2 GB
[repro-card] step 2/4 render .................. 10/10 sections filled
[repro-card] step 3/4 auto_line_matrix ......... 23 line refs injected
[repro-card] step 4/4 grep_validation .......... 23/23 numbers found
[repro-card] wrote data/data_card.md
```

## Failure modes

- Source file missing → REFUSE (card cannot be generated).
- Magic number not found in source → REFUSE (do not silently round).
- Step 4 grep mismatch under `--strict` → exit code 2.

## What this command does NOT do

- Does NOT modify existing cards; use `/repro-card <kind> --from ...`
  to regenerate from scratch.
- Does NOT create the run directory itself.
- Does NOT auto-fix grep mismatches; the human must correct.
