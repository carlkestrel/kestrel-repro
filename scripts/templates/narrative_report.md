# Narrative Report Template

> The **final report** of a paper reproduction. The user reads this and
> decides whether to publish, pivot, or drop the project. Every number
> must trace back to a file in `repro_audit/` or `experiments/<run_id>/`.

## Section structure (exactly 13, in this order)

| # | Section | Required content |
|---|---|---|
| 1 | **复现对象 / Reproduction Target** | Paper title, authors, arXiv id, target table/figure, target metric + paper value |
| 2 | **官方协议 / Official Protocol** | Training epochs, optimizer, LR schedule, batch size, augmentations, eval protocol — quoted from paper |
| 3 | **环境 / Environment** | GPU model + VRAM, CUDA, PyTorch, Python, driver versions, container hash if any |
| 4 | **数据 / Data** | Dataset name, version, split, MD5, total points, license, restricted status |
| 5 | **指标定义 / Metric Definition** | mIoU formula, per-class IoU averaging, ignore-label list — verbatim from paper |
| 6 | **代码修改 / Code Modifications** | Every file changed vs upstream commit, with rationale and diff stats |
| 7 | **L0–L3 Short-loop Results** | Pass/fail per short-loop gate + timing + memory used |
| 8 | **strict vs optimized** | Comparison of two training modes (when applicable), per-metric deltas |
| 9 | **完整训练 / Full Training** | Wall-clock, GPU-hours, peak VRAM, best epoch, best val metric, full curves |
| 10 | **论文 vs 复现值 / Paper vs Reproduced** | Side-by-side table with `Gap` column (signed) for every claim |
| 11 | **多 seed / Multi-seed** | Mean ± std across seeds; outlier analysis if any seed was excluded (and why) |
| 12 | **小类失败 / Per-class Failures** | Per-class IoU; categories with the largest gap vs paper; root-cause hypotheses |
| 13 | **未解决 + Go-Pivot-NoGo / Open + Verdict** | Open issues, plus verdict (Go/Pivot/No-Go) with confidence and supporting/blocking dimensions |

## Traceability rule (HARD requirement)

Every number in §§7–12 MUST have a citation of the form:

```
metric: [METRIC]
source: experiments/<run_id>/raw_metrics.json:line_<N>
paper:  Table X, row "..."
gap:    ±X.X pp (within ±TOLERANCE_MIOU tolerance)
```

A number without a `source:` citation is a **contract violation** and
will be flagged by `commands/repro-report.md`'s traceability check.

## Section template (per section)

```markdown
## <N>. <Section Title>

### What we did
<1-2 paragraphs>

### Results
<table or bullet list of numbers, each with `source:` citation>

### Comparison to paper
<gap column or paragraph>

### Issues
<open problems or "none">
```

## Length guidance

- Total length: **5–15 pages** Markdown rendered.
- §§7–9 are the longest (training is where most time is spent).
- §13 must be ≤ 1 page.

## Audit trail

- The narrative is generated by `commands/repro-report.md` from
  `repro_audit/*` and `experiments/<run_id>/*`.
- Human reviewers may append notes — but never delete prior content.
- A reproduction is "publishable" only when §13 verdict is GO AND no
  blocker action in `REVIEW_STATE.json` is open.
