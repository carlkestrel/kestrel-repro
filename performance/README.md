# Performance Artefacts

This directory holds **runtime performance artefacts** regenerated by the
`runtime-optimizer` and `hardware-fit-auditor` agents. They are intentionally
**gitignored** because they bind the repo to a specific host (timestamps,
measured throughput, etc.).

## What lives here

| File | Source | Regenerated by |
|------|--------|----------------|
| `baseline_metrics.csv`     | `repro_perf_tuner.py --phase health`  | `runtime-optimizer` |
| `baseline_profile.json`    | `repro_perf_tuner.py --phase profile` | `runtime-optimizer` |
| `capacity_trials.csv`      | `repro_perf_tuner.py --phase capacity` | `runtime-optimizer` |
| `hardware_inventory.json`  | `scripts/runtime/hardware_probe.py`   | `hardware-fit-auditor` |
| `health_report.md`         | `repro_perf_tuner.py --phase health`  | `runtime-optimizer` |
| `numerical_parity_report.md` | `repro_perf_tuner.py --phase parity` | `runtime-optimizer` |
| `recommendation.md`        | `repro_perf_tuner.py --phase recommend` | `runtime-optimizer` |
| `rollback.yaml`            | `repro_perf_tuner.py --phase rollback` | `runtime-optimizer` |
| `safe_capacity.yaml`       | `repro_perf_tuner.py --phase capacity` | `runtime-optimizer` |
| `soak_test_report.md`      | `scripts/runtime/soak.py`              | `runtime-optimizer` |
| `strict_performance.yaml`  | `repro_perf_tuner.py --phase profile` | `runtime-optimizer` |

## To regenerate on a new host

```bash
python scripts/runtime/repro_perf_tuner.py --phase all
python scripts/runtime/hardware_probe.py --output performance/hardware_inventory.json
```

## Versioning policy

These files are **not** checked in. The `.gitignore` entry:

```
performance/*.csv
performance/*.json
performance/*.yaml
performance/*.md
!performance/README.md
```

excludes them, while keeping this `README.md` so the directory has a clear
purpose in the tracked tree.
