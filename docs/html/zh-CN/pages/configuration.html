配置参考

配置选项和字段的完整参考

配置概述

配置按优先级从高到低合并：

  1. CLI 参数
  2. 环境变量 (REPRO_*)
  3. 项目配置文件 (.repro/config.yaml, repro.yaml)
  4. 默认值

执行模式

模式描述
strict严格复现模式（默认）。不使用优化。
optimized允许 AMP 和 DDP 优化。需要通过 parity 测试。
diagnose调试模式，放宽约束。
test测试模式，最少检查。
extend扩展原始发现。

配置字段

启动配置

字段类型默认值描述
modestringstrict执行模式
expected_cudastring-期望的 CUDA 版本
log_levelstringINFO日志级别
automationstringsafe-auto自动化策略

日志级别

级别描述
DEBUG详细调试信息
INFO信息（默认）
WARNING警告
ERROR错误

自动化策略

策略描述
safe-auto安全自动（默认）。关键决策时暂停。
manual手动审批。所有任务需要审批。
unattended无监控运行。不等待审批继续。

Gate 状态

状态描述
pending待处理
passed通过
failed失败
skipped跳过

任务状态

状态描述
PENDING等待中
READY就绪
RUNNING运行中
VERIFYING验证中
PASS通过（终态）
FAIL失败
RETRY_WAIT重试等待
WAITING_APPROVAL等待审批
APPROVED已批准
REJECTED已拒绝（终态）

环境变量

变量描述
REPRO_FAKE_GPU设为 0 模拟无 GPU
REPRO_FAKE_CUDA模拟 CUDA 版本
REPRO_FAKE_DISK_FREE模拟可用磁盘空间（字节）
HUMAN_CHECKPOINT设为 true 强制人工审批
