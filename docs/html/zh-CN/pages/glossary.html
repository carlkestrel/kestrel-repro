dl-paper-repro 核心术语定义

核心概念

论文复现 (Paper Reproduction)
验证论文中报告的实验结果的过程，确保可以独立复现。
证据链 (Evidence Chain)
记录复现过程每一步的数据和结果的审计跟踪。
数据契约 (Data Contract)
定义输入数据格式和约束的规范，确保数据一致性。
指标协议 (Metric Protocol)
定义如何计算和比较性能指标的标准方法。

Gate 系统

Gate 0 - 环境
验证软件环境、依赖和配置。
Gate 1 - 数据
验证数据集完整性、格式和下载。
Gate 2 - 代码
验证代码适配性和运行时正确性。
Gate 3 - 基线
验证基线训练可以正常运行。
Gate 4 - 对比
对比复现结果与原始论文报告。
Gate 5 - 审计
最终审计和报告生成。

执行模式

Strict Mode
严格复现模式，不允许优化。
Optimized Mode
优化复现模式，允许 AMP、DDP 等优化。
Diagnose Mode
诊断模式，用于调试。
Test Mode
测试模式，最小检查。
Extend Mode
扩展模式，用于在原始结果上扩展。

短循环测试

L0 - 冒烟测试
基本功能验证。
L1 - 过拟合测试
验证模型在小数据集上过拟合。
L2 - 小循环测试
端到端小规模运行。
L3 - 恢复测试
验证从中断恢复。

系统组件

编排器 (Orchestrator)
任务调度和状态管理。
验证器 (Verifier)
验证任务执行结果。
存储管理器 (Storage Governor)
管理磁盘空间和清理策略。
执行控制器 (Execution Controller)
控制任务执行流程。
策略引擎 (Policy Engine)
执行存储和执行策略。
监控守护进程 (Watchdog)
监控任务状态和健康。

状态值

PASS
检查通过。
FAIL
检查失败。
PENDING
等待处理。
RUNNING
正在运行。
SKIPPED
已跳过。
