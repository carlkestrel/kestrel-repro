常见问题

关于 dl-paper-repro 的常见问题

一般问题

Q: dl-paper-repro 是什么？

dl-paper-repro 是一个基于证据驱动的深度学习论文仓库复现、审计和硬件优化系统。它提供结构化的工作流来复现论文中的实验结果。

Q: 为什么要使用论文复现工具？

论文复现对于验证研究结果的可靠性和可复现性至关重要。它帮助研究者：

  • 验证论文结果
  • 理解实现细节
  • 在此基础上进行改进
  • 建立可复现性基线

设置问题

Q: 系统要求是什么？

  • Python 3.9+
  • PyTorch 1.10+
  • CUDA 11.3+（用于 GPU 训练）
  • 8GB+ RAM
  • 50GB+ 可用磁盘空间

Q: 安装失败怎么办？

  1. 检查 Python 版本：python --version
  2. 创建新的虚拟环境
  3. 安装依赖：pip install -e .

工作流问题

Q: Gate 系统是什么？

Gate 系统是分阶段的质量门控：

  • Gate 0: 环境准备
  • Gate 1: 数据准备
  • Gate 2: 代码适配
  • Gate 3: 基线验证
  • Gate 4: 结果对比
  • Gate 5: 最终审计

Q: strict 和 optimized 模式有什么区别？

特性strictoptimized
优化无AMP, DDP, PP
容差±0.5%±0.5%
Gate 3 要求否是

Q: 什么是检查点？

检查点是在执行过程中的暂停点，需要人工审批才能继续。这确保了研究者在关键阶段进行验证。

技术问题

Q: 需要 GPU 吗？

强烈建议使用 GPU 进行训练。如果只有 CPU，可以使用 diagnose 或 test 模式进行小规模测试。

Q: 如何准备数据集？

参考 Gate 1 的数据准备指南。系统支持：

  • 自动下载公共数据集
  • 自定义数据路径
  • 数据完整性验证

Q: 支持多 GPU 吗？

是的。使用 optimized 模式并启用 DDP（分布式数据并行）即可。

故障排除

Q: 常见错误有哪些？

  • EXIT_DOCTOR_FAIL: Doctor 检查失败，查看报告
  • EXIT_LOCK_HELD: 锁文件被占用
  • EXIT_INVALID_PLAN: 无效的计划文件
  • EXIT_GATE_FAILED: Gate 检查失败

Q: 如何重置项目？

python scripts/reproctl.py stop --project .
rm -rf .repro/
