dl-paper-repro 的目录和文件结构

插件结构

dl-paper-repro/
├── .cursor-plugin/
│   └── plugin.json              # Cursor 插件清单
├── agents/                      # Agent 定义
│   ├── skill.json
│   └── ...
├── commands/                    # Cursor 命令 (Markdown)
│   ├── repro-discover.md
│   ├── repro-contract.md
│   └── ...
├── docs/                        # 文档
│   ├── README.md
│   ├── architecture.md
│   └── ...
├── rules/                       # Cursor 规则
├── schemas/                     # JSON Schema
│   ├── config.schema.json
│   ├── plan.schema.json
│   └── ...
├── scripts/                      # Python 脚本 (核心)
│   ├── reproctl.py              # 唯一 CLI 入口
│   ├── startup/                  # 启动子系统
│   └── orchestrator/            # 编排器子系统
├── skills/                      # Cursor Skills
├── templates/                    # 模板文件
└── tests/                       # 测试

运行时结构

project/
├── .repro/
│   ├── config.yaml              # 用户配置
│   ├── repro.yaml               # 项目配置
│   ├── run.lock                 # PID 锁
│   ├── repro_audit/
│   │   ├── STATE.json          # 状态
│   │   ├── DECISION_LOG.md     # 决策日志
│   │   └── checkpoints/
│   ├── startup/
│   │   ├── startup.log
│   │   ├── startup_state.json
│   │   └── doctor_report.json
│   └── execution/
│       ├── execution_state.json
│       ├── state.sqlite3        # SQLite WAL
│       ├── controller.pid
│       └── checkpoints/
├── primary/                     # 主要仓库
├── reference/                   # 参考仓库
├── experiments/
│   └── experiment_tracker.csv  # 实验跟踪
└── output/                      # 输出
    ├── PAPER_PLAN.md
    ├── manuscript/
    └── figures/
