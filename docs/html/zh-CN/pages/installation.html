安装指南

设置 dl-paper-repro 环境

环境要求

组件要求
Python3.8+
PyTorch最新版本（用于 GPU 训练）
CUDA12.0+（可选，用于 GPU 训练）
磁盘空间至少 10 GB（用于代码、数据集、检查点）

安装步骤

1. 克隆仓库

git clone https://github.com/your-org/dl-paper-repro.git ~/.cursor/plugins/local/dl-paper-repro

2. 安装依赖

cd ~/.cursor/plugins/local/dl-paper-repro
pip install -e .

3. 验证安装

python scripts/reproctl.py version

PyTorch 和 CUDA 设置

GPU 训练

# 安装 PyTorch with CUDA
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

验证 CUDA

python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}'); print(f'CUDA version: {torch.version.cuda}')"

环境变量

可选的环境变量用于配置行为：

变量默认值描述
REPRO_FAKE_GPU-设为 0 模拟无 GPU 环境
REPRO_FAKE_CUDA-模拟特定 CUDA 版本
REPRO_FAKE_DISK_FREE-模拟可用磁盘空间（字节）
HUMAN_CHECKPOINTfalse设为 true 强制人工审批

验证设置

安装完成后，运行 Doctor 检查验证环境：

python scripts/reproctl.py doctor --project .

Doctor 检查应报告所有项目为 PASS 或 WARNING。如果有任何 FAIL，请参阅故障排除页面。
