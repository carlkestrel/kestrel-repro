安全

敏感信息保护和安全最佳实践

敏感信息脱敏

脱敏规则

scripts/startup/secrets_redactor.py 脱敏以下模式：

模式替换
Bearer <token>Bearer [脱敏]
password=*password=[脱敏]
token=*token=[脱敏]
Authorization: *Authorization: [脱敏]
AWS_SECRET*[脱敏]
OPENAI_API_KEY*[脱敏]

凭证管理

环境变量

# 设置 API token
export GITHUB_TOKEN=ghp_xxxxx

最佳实践

  1. 不要硬编码：使用环境变量或密钥管理服务
  2. 不要提交：确保 .gitignore 包含敏感文件
  3. 不要日志：敏感信息会被脱敏，但尽量避免记录

文件权限

# 设置权限
chmod 600 .repro/run.lock
chmod 600 .repro/execution/state.sqlite3

# 限制目录访问
chmod 700 .repro/

安全事件响应

检测到敏感信息泄露

  1. 立即轮换凭证
  2. 删除泄露内容
  3. 检查 git 历史
  4. 报告安全事件
