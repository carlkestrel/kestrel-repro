系统架构

了解 dl-paper-repro 的三层架构

架构概述

dl-paper-repro 采用三层架构：

核心组件

CLI 层

reproctl.py 是唯一入口点，分发到：

  • 启动 CLI (startup/cli.py)：start, doctor, status, resume, stop, verify, version
  • 编排器 CLI (orchestrator/cli.py)：run, pause, continue, events, approve, reject, daemon
  • 遗留命令：init, launch, can-launch, report, update-gate（向后兼容）

StateStore (SQLite)

编排器使用带 WAL 模式的 SQLite 进行持久化状态：

数据库模式

-- 数据库: .repro/execution/state.sqlite3
-- 模式: WAL (预写日志)

-- metadata: 键值控制状态
CREATE TABLE metadata (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
-- 键: control_state, plan_id, plan_path, mode, automation, mandatory_task_ids, budgets

-- tasks: 任务定义和状态
CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  gate TEXT NOT NULL,
  deps_json TEXT NOT NULL,
  command TEXT NOT NULL,
  timeout_min REAL NOT NULL,
  acceptance_json TEXT NOT NULL,
  retry_json TEXT NOT NULL,
  task_json TEXT NOT NULL,
  status TEXT NOT NULL,
  attempts INTEGER DEFAULT 0,
  pid INTEGER,
  log_path TEXT,
  started_at TEXT,
  finished_at TEXT,
  retry_at REAL,
  failure_reason TEXT,
  updated_at TEXT NOT NULL
);

-- approvals: 人工审批工作流
CREATE TABLE approvals (
  approval_id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  status TEXT NOT NULL,
  reason TEXT,
  created_at TEXT NOT NULL,
  expires_at REAL,
  decided_at TEXT
);

-- events: 事件日志
CREATE TABLE events (
  seq INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,
  event_type TEXT NOT NULL,
  task_id TEXT,
  payload_json TEXT NOT NULL
);

-- heartbeats: 进程心跳
CREATE TABLE heartbeats (
  owner TEXT PRIMARY KEY,
  pid INTEGER NOT NULL,
  timestamp REAL NOT NULL,
  detail_json TEXT NOT NULL
);

任务状态机

任务遵循定义的状态转换机：

有效转换

从到触发器
PENDINGREADY依赖满足
READYRUNNING调度器选择任务
RUNNINGVERIFYING命令完成
VERIFYINGPASS验收测试通过
VERIFYINGFAIL验收测试失败
FAILRETRY_WAIT重试策略允许
RETRY_WAITREADY重试延迟已过
READYWAITING_APPROVAL策略需要审批
WAITING_APPROVALAPPROVED人工批准
WAITING_APPROVALREJECTED人工拒绝

门控系统

六个分阶段门控确保继续前的质量：

Gate名称描述
gate_0论文审计验证论文数据和声明
gate_1预检环境和依赖
gate_2短循环L0-L3 验证测试
gate_3奇偶校验优化奇偶性检查
gate_4完整训练完整训练运行
gate_5证据最终证据验证

退出码

代码名称描述
0成功命令成功完成
1失败一般失败或参数错误
2配置错误配置验证失败
3EXIT_DOCTOR_FAILDoctor 检查失败（必需项）
4EXIT_ALREADY_RUNNING另一个实例正在运行
5INVALID_PLAN计划文件无效或缺失
6TASK_FAILED任务执行失败
7TASK_BLOCKED所有任务被阻塞（编排器）
8EXIT_RESUME_FAILED恢复失败
9SECURITY_BLOCKED安全检查阻止操作
10INTERNAL_ERROR内部错误（导入等）
