快速上手指南

5 分钟内启动 dl-paper-repro

命令工作流

典型的项目生命周期遵循以下序列：

1
python scripts/reproctl.py doctor --project .

运行预检以验证环境

2
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

引导并启动项目

3
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md

运行任务编排器

4
python scripts/reproctl.py orchestrator status --project .

监控项目状态

5
python scripts/reproctl.py orchestrator pause --project .

如需要，暂停执行

6
python scripts/reproctl.py orchestrator continue --project .

恢复执行

7
python scripts/reproctl.py stop --project .

完成后优雅停止

8
python scripts/reproctl.py verify --project .

验证证据链

命令示例

Doctor 检查

# 运行预检
python scripts/reproctl.py doctor --project .

# 指定期望的 CUDA 版本
python scripts/reproctl.py doctor --project . --expected-cuda 12.0

# 预期输出:
# {
#   "checks": [...],
#   "summary": "PASS",
#   "exit_code": 0
# }

启动项目

# 以严格模式启动
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

# 预演（不获取锁）
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --dry-run

# 以优化模式启动
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode optimized

查看状态

# 启动状态
python scripts/reproctl.py status --project .

# 编排器状态
python scripts/reproctl.py orchestrator status --project .

# 预期输出:
# {
#   "project_root": "/path/to/project",
#   "control_state": "RUNNING",
#   "counts": {"PASS": 5, "RUNNING": 1, "PENDING": 3},
#   "tasks": [...],
#   "pending_approvals": [...]
# }

恢复

# 恢复中断的项目
python scripts/reproctl.py resume --project .

停止

# 优雅停止
python scripts/reproctl.py stop --project .

验证

# 验证证据链
python scripts/reproctl.py verify --project .

# 退出码:
# 0 = 验证通过
# 8 = 验证失败

退出码

代码含义
0成功
1失败 / 参数错误
2配置错误
3Doctor 检查失败
4已在运行
5无效计划
8恢复失败
10内部错误
