复现协议

论文复现的标准流程和验收标准

概述

复现协议定义了论文复现的标准流程和验收标准。

复现阶段

Gate 0: 论文审计

目标：验证论文数据和声明的完整性。

检查项：

  • 论文 PDF 可访问
  • 论文声明可提取
  • 目标指标已定义
  • 数据集可用
  • 硬件要求明确

Gate 1: 预检

目标：验证环境满足复现要求。

检查项：

  • Python 环境正确
  • PyTorch 安装
  • CUDA 版本匹配
  • GPU 可用
  • 磁盘空间充足
  • 依赖安装完成

Gate 2: 短循环测试

目标：验证代码可运行且基本正确。

L0: 冒烟测试

python scripts/reproctl.py run-short-loop --level L0

检查项：

  • 单批次前向传播成功
  • 单批次反向传播成功
  • 梯度计算正确
  • 损失函数输出有效值

L1: 过拟合测试

python scripts/reproctl.py run-short-loop --level L1 --overfit-steps 100

L2: 小数据集循环

python scripts/reproctl.py run-short-loop --level L2 --epochs 3

L3: 检查点恢复

python scripts/reproctl.py run-short-loop --level L3

Gate 3: 奇偶校验

目标：验证优化和标准实现的一致性。

Gate 4: 完整训练

目标：运行完整训练并达到目标指标。

Gate 5: 证据链

目标：生成完整的可审计证据链。

指标验收标准

严格模式 (strict_repro)

指标类型容差
主要指标±0.5 pp
次要指标±1.0 pp
效率指标±10%
