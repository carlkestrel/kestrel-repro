启动命令

这些命令管理项目生命周期，使用 python scripts/reproctl.py <命令>：

start

使用统一入口引导和启动项目。

python scripts/reproctl.py start --project PATH --plan PLAN [--mode MODE] [--dry-run] [--expected-cuda VERSION]
参数必选默认值描述
--project是-项目根目录
--plan是-计划文件路径
--mode否strict执行模式 (strict/optimized/diagnose/test/extend)
--dry-run否false仅检查，不获取锁
--expected-cuda否-期望的 CUDA 版本

doctor

运行预检（无状态变更）。

python scripts/reproctl.py doctor --project PATH [--expected-cuda VERSION]

退出码：0 表示 PASS/WARNING，3 表示 FAIL。

status

显示项目状态、锁状态和计划哈希。

python scripts/reproctl.py status --project PATH

resume

恢复中断的项目。

python scripts/reproctl.py resume --project PATH

退出码：0 成功，2 配置错误，4 已在运行，8 恢复失败。

stop

优雅停止并清除锁。

python scripts/reproctl.py stop --project PATH

verify

验证启动证据链。

python scripts/reproctl.py verify --project PATH

version

打印插件和 CLI 版本。

python scripts/reproctl.py version

遗留命令

这些命令为保持向后兼容而保留：

init

python scripts/reproctl.py init [--paper URL] [--target METRIC]

can-launch

python scripts/reproctl.py can-launch [--mode MODE]
# 模式: strict_repro, optimized_repro_safe, experimental_fast

launch

python scripts/reproctl.py launch [--mode MODE] [--seed SEED] [--epochs EPOCHS] [--config CONFIG] [extra...]

run-short-loop

python scripts/reproctl.py run-short-loop [--level LEVEL] [--config CONFIG] [--overfit-steps STEPS] [--epochs EPOCHS]
# 级别: L0, L1, L2, L3, all (默认)

编排器命令

长时间运行任务的持久化控制器。使用 python scripts/reproctl.py orchestrator <命令>：

命令描述
run启动持久化控制器循环
pause暂停编排器
continue继续编排器
stop停止编排器
status显示状态摘要
events事件日志流
next显示下一个任务
approve批准待审批任务
reject拒绝待审批任务
daemon后台守护进程控制
migrate状态迁移
backup创建备份快照
restore从备份恢复
integrity-check完整性验证
rollback-version回滚到指定版本

存储命令

磁盘策略和保留管理。使用 python scripts/reproctl.py storage <命令>：

命令描述
status根据策略检查磁盘空间
plan-cleanup生成清理计划（预演）
cleanup执行已批准的清理计划
apply应用保留/磁盘策略配置
