快速操作

5 分钟快速开始

运行预检并引导您的第一个复现项目。

python scripts/reproctl.py doctor --project .
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

项目接管

恢复中断或现有的复现项目。

python scripts/reproctl.py status --project .
python scripts/reproctl.py resume --project .

核心命令

所有命令使用 python scripts/reproctl.py <命令>：

命令 类别 描述 状态
doctor 启动 运行预检（无状态变更） 稳定
start 启动 引导和启动项目 稳定
status 启动 显示项目状态和锁状态 稳定
resume 启动 恢复中断的项目 稳定
stop 启动 优雅停止并清除锁 稳定
verify 启动 验证启动证据链 稳定
version 启动 打印插件和 CLI 版本 稳定
orchestrator run 编排器 运行持久化控制器循环 稳定
orchestrator daemon 编排器 后台守护进程控制 稳定
storage 存储 磁盘策略和清理 稳定

功能状态

功能 状态 描述
启动系统 稳定 项目初始化、预检、锁管理
编排器 稳定 任务调度、执行、使用 SQLite 状态监控
Gate 0-5 系统 稳定 分阶段复现门控与证据跟踪
L0-L3 短循环 稳定 冒烟测试、过拟合测试、小循环、恢复测试
存储治理 稳定 磁盘策略、保留、清理规划
备份与恢复 稳定 状态快照和恢复
人工检查点 稳定 12 项强制暂停-询问工作流
敏感信息脱敏 稳定 凭证检测和日志清理
GitHub 爬虫 测试版 仓库发现和评估
点云支持 实验性 点云论文专业复现

执行模式

为您的复现目标选择合适的模式：

模式 描述 需要 Gate 3
strict 严格复现，无优化 否
optimized 允许 AMP 和 DDP 优化 是（需要 parity 测试）
diagnose 调试模式，放宽约束 否
test 测试模式，最少检查 否
extend 扩展原始发现 不定
关于容差的说明

strict 和 optimized 模式都允许报告指标 ±0.5 个百分点的容差。

安全注意事项

API 令牌

切勿在配置文件中硬编码 API 令牌或凭证。使用环境变量，并确保 .repro/ 在您的 .gitignore 中。

敏感信息扫描

doctor 命令会扫描常见凭证模式，并在检测到时发出警告。分享日志前请先审查。
