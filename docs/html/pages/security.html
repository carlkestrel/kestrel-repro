Security

Secrets management and security best practices

Secrets Redaction

Doctor automatically scans for secrets. Patterns detected:

PatternReplaced With
Bearer <token>Bearer [REDACTED]
password=*password=[REDACTED]
token=*token=[REDACTED]
Authorization:Authorization: [REDACTED]
AWS_SECRET*[REDACTED]
OPENAI_API_KEY*[REDACTED]

Credential Management

Never hardcode credentials

Use environment variables and ensure .repro/ is in .gitignore.

# Set via environment
export GITHUB_TOKEN=ghp_xxxxx

# Use in config
# repro.yaml
github:
  token: ${GITHUB_TOKEN}

File Permissions

# Set permissions
chmod 600 .repro/run.lock
chmod 600 .repro/execution/state.sqlite3
chmod 700 .repro/

5 Principles

The system enforces 5 core principles:

  1. require_official_first - Paper author repo first
  2. require_strict_mode - Default to strict_repro
  3. require_raw_metrics - Metrics traceable to files
  4. require_provenance - Commit SHA required
  5. require_reproducibility - Results match within tolerance
