Parameters

ParameterDescriptionDefault
--querySearch queryRequired
--max-resultsMaximum results50
--languageProgramming languagepython
--stars-minMinimum stars0
--sortSort bystars

Repository Evaluation

Repositories are evaluated on:

  • is_official - Paper author repository (high weight)
  • stars - Community popularity
  • has_train - Training scripts available
  • has_readme - Documentation present
  • license - Usage permissions
  • last_commit - Active maintenance

Cursor Commands

Use these commands in Cursor:

  • /repro-discover - Find candidate repositories
  • /repro-contract - Evaluate and select repository
