Command Reference

Complete reference for all reproctl commands

Startup Commands

These commands manage the project lifecycle and use python scripts/reproctl.py <command>:

start

Bootstrap and start the project with unified entry point.

python scripts/reproctl.py start --project PATH --plan PLAN [--mode MODE] [--dry-run] [--expected-cuda VERSION]
ArgumentRequiredDefaultDescription
--projectYes-Project root directory
--planYes-Plan file path
--modeNostrictExecution mode (strict/optimized/diagnose/test/extend)
--dry-runNofalseCheck only, no lock acquired
--expected-cudaNo-Expected CUDA version

doctor

Run preflight checks without state mutation.

python scripts/reproctl.py doctor --project PATH [--expected-cuda VERSION]

Exit codes: 0 for PASS/WARNING, 3 for FAIL.

status

Show project state, lock status, and plan hash.

python scripts/reproctl.py status --project PATH

resume

Resume an interrupted project.

python scripts/reproctl.py resume --project PATH

Exit codes: 0 success, 2 config error, 4 already running, 8 recovery failed.

stop

Stop gracefully and clear the lock.

python scripts/reproctl.py stop --project PATH

verify

Verify the startup evidence chain.

python scripts/reproctl.py verify --project PATH

version

Print plugin and CLI version.

python scripts/reproctl.py version

Legacy Commands

These commands are retained for backward compatibility:

init

python scripts/reproctl.py init [--paper URL] [--target METRIC]

can-launch

python scripts/reproctl.py can-launch [--mode MODE]
# Modes: strict_repro, optimized_repro_safe, experimental_fast

launch

python scripts/reproctl.py launch [--mode MODE] [--seed SEED] [--epochs EPOCHS] [--config CONFIG] [extra...]

run-short-loop

python scripts/reproctl.py run-short-loop [--level LEVEL] [--config CONFIG] [--overfit-steps STEPS] [--epochs EPOCHS]
# Levels: L0, L1, L2, L3, all (default)

Orchestrator Commands

Persistent controller for long-running tasks. Use python scripts/reproctl.py orchestrator <command>:

CommandDescription
runStart persistent controller loop
pausePause orchestrator
continueContinue orchestrator
stopStop orchestrator
statusShow state summary
eventsEvent log stream
nextShow next task
approveApprove pending task
rejectReject pending task
daemonBackground daemon control
migrateState migration
backupCreate backup snapshot
restoreRestore from backup
integrity-checkIntegrity verification
rollback-versionRollback to version
