Automation Workflow

Configure and run automated task execution

Autopilot (NORA-style)

The autopilot.py command provides a unified NORA-style entry point for continuous paper reproduction execution. It wraps the orchestrator with additional features for GPU monitoring, recovery, and status reporting.

# Start autopilot - continuous execution until blocked or complete
python scripts/autopilot.py run --project . --until blocked-or-complete

# Check status
python scripts/autopilot.py status --project .

# Recover from interruption
python scripts/autopilot.py recover --project .

# Pause/Stop/Continue
python scripts/autopilot.py pause --project .
python scripts/autopilot.py stop --project .
python scripts/autopilot.py continue --project .

# Takeover existing project
python scripts/autopilot.py takeover --project .

Autopilot Commands

CommandDescription
runContinuous execution with automatic recovery
statusShow autopilot status, task counts, and heartbeat
recoverRecover from interrupted state
takeoverAnalyze and takeover existing project
eventsStream the event log
approveApprove a pending task
rejectReject a pending task
daemonControl daemon mode

Run Options

OptionDefaultDescription
--automationsafe-autoAutomation level: safe-auto, auto, manual
--untilblocked-or-completeRun until: blocked, complete, blocked-or-complete, always
--mode-Execution mode: strict, optimized
--resumefalseResume from interrupted state
--skip-doctorfalseSkip preflight checks

Automation Modes

ModeDescription
safe-autoDefault. Pauses for approval on critical decisions.
autoMore permissive, fewer approval gates.
manualAll tasks require approval.

Daemon Mode

Run the autopilot as a background daemon:

# Start daemon
python scripts/autopilot.py daemon --project . start --plan output/PAPER_PLAN.md

# Check status
python scripts/autopilot.py daemon --project . status

# Stop daemon
python scripts/autopilot.py daemon --project . stop

Or using the legacy reproctl command:

# Start daemon
python scripts/reproctl.py orchestrator daemon --project . start --plan output/PAPER_PLAN.md

# Check status
python scripts/reproctl.py orchestrator daemon --project . status

# Stop daemon
python scripts/reproctl.py orchestrator daemon --project . stop

Policy Files

Create a policy file to control task approval:

{
  "policy_id": "custom-policy",
  "rules": [
    {"condition": "task.gate == 'gate_0'", "action": "auto_approve"},
    {"condition": "task.timeout_min > 60", "action": "require_approval"}
  ],
  "defaults": {
    "approval_required": false,
    "retry_on_failure": true,
    "max_retries": 3
  }
}
# Use policy
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md --policy policy.json

Approval Workflow

# View pending approvals
python scripts/reproctl.py orchestrator status --project .

# Approve
python scripts/reproctl.py orchestrator approve --project . apr_xxxxx

# Reject
python scripts/reproctl.py orchestrator reject --project . apr_xxxxx --reason "reason"

Run Strategies

# Until blocked or complete
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md --until blocked-or-complete

# Until complete
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md --until complete

# Run indefinitely
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md
