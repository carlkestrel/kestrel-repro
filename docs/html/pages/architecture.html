System Architecture

Understanding the three-layer architecture of dl-paper-repro

Architecture Overview

dl-paper-repro uses a three-layer architecture:

Core Components

CLI Layer

reproctl.py is the single entry point that dispatches to:

  • Startup CLI (startup/cli.py): start, doctor, status, resume, stop, verify, version
  • Orchestrator CLI (orchestrator/cli.py): run, pause, continue, events, approve, reject, daemon
  • Legacy Commands: init, launch, can-launch, report, update-gate (backward compatible)

StateStore (SQLite)

The orchestrator uses SQLite with WAL mode for persistent state:

Database Schema

-- Database: .repro/execution/state.sqlite3
-- Mode: WAL (Write-Ahead Logging)

-- metadata: key-value control state
CREATE TABLE metadata (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
-- Keys: control_state, plan_id, plan_path, mode, automation, mandatory_task_ids, budgets

-- tasks: task definitions and state
CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  gate TEXT NOT NULL,
  deps_json TEXT NOT NULL,
  command TEXT NOT NULL,
  timeout_min REAL NOT NULL,
  acceptance_json TEXT NOT NULL,
  retry_json TEXT NOT NULL,
  task_json TEXT NOT NULL,
  status TEXT NOT NULL,
  attempts INTEGER DEFAULT 0,
  pid INTEGER,
  log_path TEXT,
  started_at TEXT,
  finished_at TEXT,
  retry_at REAL,
  failure_reason TEXT,
  updated_at TEXT NOT NULL
);

-- approvals: human approval workflow
CREATE TABLE approvals (
  approval_id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  status TEXT NOT NULL,
  reason TEXT,
  created_at TEXT NOT NULL,
  expires_at REAL,
  decided_at TEXT
);

-- events: event journal
CREATE TABLE events (
  seq INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,
  event_type TEXT NOT NULL,
  task_id TEXT,
  payload_json TEXT NOT NULL
);

-- heartbeats: process heartbeats
CREATE TABLE heartbeats (
  owner TEXT PRIMARY KEY,
  pid INTEGER NOT NULL,
  timestamp REAL NOT NULL,
  detail_json TEXT NOT NULL
);

Six staged gates ensure quality before proceeding:

gate_3ParityOptimization parity check
