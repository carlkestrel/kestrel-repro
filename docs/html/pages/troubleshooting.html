Troubleshooting Guide

Fix common issues with diagnosis by symptom

Doctor Check Failures

Run doctor to identify environment issues:

python scripts/reproctl.py doctor --project .
cat .repro/startup/doctor_report.json

Common Failures

CheckCauseFix
cuda_matchCUDA version mismatchInstall correct CUDA or use --expected-cuda
disk_spaceNot enough free spaceFree up disk space
securitySecrets detected in filesRemove sensitive information
leftover_procsOld processes still runningStop old instances

Lock Conflicts

EXIT_ALREADY_RUNNING: 4

Another instance is already running or a stale lock exists.

# Check lock contents
cat .repro/run.lock

# Check if PID exists
ps aux | grep 

# Stop old instance
python scripts/reproctl.py stop --project .

# Or manually remove lock
rm .repro/run.lock

Recovery Failures

EXIT_RESUME_FAILED: 8

Could not recover from interrupted state.

# Check execution state
cat .repro/execution/execution_state.json

# Reinitialize with dry-run
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --dry-run

SQLite Database Locked

The SQLite database is locked by another process:

# Check WAL files
ls -la .repro/execution/state.sqlite3*

# Remove WAL to release lock
rm .repro/execution/state.sqlite3-wal
rm .repro/execution/state.sqlite3-shm

# Restart orchestrator
python scripts/reproctl.py orchestrator stop --project .
python scripts/reproctl.py orchestrator daemon --project . start --plan output/PAPER_PLAN.md

GPU Issues

# Check CUDA
python -c "import torch; print(torch.cuda.is_available())"
python -c "import torch; print(torch.version.cuda)"

# Check driver
nvidia-smi

# Skip GPU check (for testing)
REPRO_FAKE_GPU=0 python scripts/reproctl.py doctor --project .

Approval Workflow Stuck

Tasks stuck in WAITING_APPROVAL state:

# Check pending approvals
python scripts/reproctl.py orchestrator status --project .

# Approve task
python scripts/reproctl.py orchestrator approve --project . apr_xxxxx

# Or reject
python scripts/reproctl.py orchestrator reject --project . apr_xxxxx --reason "reason"

Diagnostic Commands

# 1. Environment
python scripts/reproctl.py doctor --project .

# 2. Project status
python scripts/reproctl.py status --project .
python scripts/reproctl.py orchestrator status --project .

# 3. Events
python scripts/reproctl.py orchestrator events --project . --limit 50

# 4. Logs
cat .repro/startup/startup.log
cat .repro/execution/daemon.log

# 5. Integrity
python scripts/reproctl.py orchestrator integrity-check --project .
python scripts/reproctl.py integrity-check
