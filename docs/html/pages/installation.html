Installation

Set up dl-paper-repro for your reproduction projects

Plugin Installation

The Cursor plugin is installed by placing it in your Cursor plugins directory:

# Clone or copy the plugin to your local plugins directory
git clone https://github.com/research-automation/dl-paper-repro.git \
  ~/.cursor/plugins/local/dl-paper-repro

# Verify the plugin is recognized
ls ~/.cursor/plugins/local/dl-paper-repro/

After placing the plugin, restart Cursor to load it. The plugin will appear in your Cursor settings under "Local Plugins".

CLI Setup

You can use the CLI directly with Python or install it as a package:

# Option 1: Use directly with Python
python ~/.cursor/plugins/local/dl-paper-repro/scripts/reproctl.py --help

# Option 2: Install in editable mode
cd ~/.cursor/plugins/local/dl-paper-repro
pip install -e .

# Now use from anywhere
reproctl --help

Verification

Verify the installation by checking the version and running a doctor check:

# Check version
python scripts/reproctl.py version

# Expected output:
# {
#   "reproctl": "0.2.0",
#   "plugin": "0.2.0",
#   "plugin_root": "/path/to/plugin",
#   "platform": "linux"
# }

# Run doctor to verify environment
python scripts/reproctl.py doctor --project .

GPU Setup

For GPU training, ensure CUDA is properly installed:

# Verify CUDA is available
python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}')"
python -c "import torch; print(f'CUDA version: {torch.version.cuda}')"

# Check nvidia-smi
nvidia-smi
No GPU?

You can run with REPRO_FAKE_GPU=0 to skip GPU checks during development or testing.
