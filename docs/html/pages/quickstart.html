Quick Start Guide

Get up and running with dl-paper-repro in 5 minutes

Command Workflow

The typical project lifecycle follows this sequence:

1
python scripts/reproctl.py doctor --project .

Run preflight checks to verify environment

2
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

Bootstrap and start the project

3
python scripts/reproctl.py orchestrator run --project . --plan output/PAPER_PLAN.md

Run the task orchestrator

4
python scripts/reproctl.py orchestrator status --project .

Monitor project status

5
python scripts/reproctl.py orchestrator pause --project .

Pause execution if needed

6
python scripts/reproctl.py orchestrator continue --project .

Resume execution

7
python scripts/reproctl.py stop --project .

Stop gracefully when done

8
python scripts/reproctl.py verify --project .

Verify the evidence chain

Command Examples

Doctor Check

# Run preflight checks
python scripts/reproctl.py doctor --project .

# Specify expected CUDA version
python scripts/reproctl.py doctor --project . --expected-cuda 12.0

# Expected output:
# {
#   "checks": [...],
#   "summary": "PASS",
#   "exit_code": 0
# }

Start Project

# Start in strict mode
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

# Dry run (no lock acquired)
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --dry-run

# Start in optimized mode
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode optimized

Check Status

# Startup status
python scripts/reproctl.py status --project .

# Orchestrator status
python scripts/reproctl.py orchestrator status --project .

# Expected output:
# {
#   "project_root": "/path/to/project",
#   "control_state": "RUNNING",
#   "counts": {"PASS": 5, "RUNNING": 1, "PENDING": 3},
#   "tasks": [...],
#   "pending_approvals": [...]
# }

Resume

# Resume interrupted project
python scripts/reproctl.py resume --project .

Stop

# Graceful stop
python scripts/reproctl.py stop --project .

Verify

# Verify evidence chain
python scripts/reproctl.py verify --project .

# Exit codes:
# 0 = verification passed
# 8 = verification failed

Exit Codes

CodeMeaning
0Success
1Failure / parameter error
2Configuration error
3Doctor check failed
4Already running
5Invalid plan
8Recovery failed
10Internal error
