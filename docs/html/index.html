Quick Actions

5-Minute Start

Run preflight checks and bootstrap your first reproduction project.

python scripts/reproctl.py doctor --project .
python scripts/reproctl.py start --project . --plan output/PAPER_PLAN.md --mode strict

Takeover Project

Resume an interrupted or existing reproduction project.

python scripts/reproctl.py status --project .
python scripts/reproctl.py resume --project .

Core Commands

All commands use python scripts/reproctl.py <command>:

Command Category Description Status
doctor Startup Run preflight checks (no state mutation) STABLE
start Startup Bootstrap and start project STABLE
status Startup Show project state and lock status STABLE
resume Startup Resume interrupted project STABLE
stop Startup Stop gracefully and clear lock STABLE
verify Startup Verify startup evidence chain STABLE
version Startup Print plugin and CLI version STABLE
orchestrator run Orchestrator Run persistent controller loop STABLE
orchestrator daemon Orchestrator Background daemon control STABLE
storage Storage Disk policy and cleanup STABLE

Execution Modes

Choose the appropriate mode for your reproduction goals:

Mode Description Gate 3 Required
strict Exact paper reproduction, no optimizations No
optimized Allow AMP and DDP optimizations Yes (parity test)
diagnose Debug mode, relaxed constraints No
test Testing mode with minimal checks No
extend Extend original findings Varies
Note on Tolerance

Both strict and optimized modes allow ±0.5 percentage points tolerance on reported metrics.

Security Notices

API Tokens

Never hardcode API tokens or credentials in config files. Use environment variables and ensure .repro/ is in your .gitignore.

Secrets Scanning

The doctor command scans for common credential patterns and will warn if detected. Review logs before sharing.
