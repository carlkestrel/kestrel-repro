# 复现协议

## 概述

复现协议定义了论文复现的标准流程和验收标准。

## 复现阶段

### Phase 0: 论文审计 (Gate 0)

#### 目标
验证论文数据和声明的完整性。

#### 检查项
- [ ] 论文 PDF 可访问
- [ ] 论文声明可提取
- [ ] 目标指标已定义
- [ ] 数据集可用
- [ ] 硬件要求明确

#### 证据
- `paper_audit.md`
- 指标提取记录
- 数据集下载记录

---

### Phase 1: 预检 (Gate 1)

#### 目标
验证环境满足复现要求。

#### 检查项
- [ ] Python 环境正确
- [ ] PyTorch 安装
- [ ] CUDA 版本匹配
- [ ] GPU 可用
- [ ] 磁盘空间充足
- [ ] 依赖安装完成

#### 证据
- `doctor_report.json`

---

### Phase 2: 短循环测试 (Gate 2)

#### 目标
验证代码可运行且基本正确。

#### L0: 冒烟测试

```bash
python scripts/reproctl.py run-short-loop --level L0
```

**检查项**:
- [ ] 单批次前向传播成功
- [ ] 单批次反向传播成功
- [ ] 梯度计算正确
- [ ] 损失函数输出有效值

---

#### L1: 过拟合测试

```bash
python scripts/reproctl.py run-short-loop --level L1 --overfit-steps 100
```

**检查项**:
- [ ] 单批次过拟合成功
- [ ] 损失下降
- [ ] 精度提升
- [ ] 无 NaN/Inf

---

#### L2: 小数据集循环

```bash
python scripts/reproctl.py run-short-loop --level L2 --epochs 3
```

**检查项**:
- [ ] 端到端训练成功
- [ ] 检查点保存成功
- [ ] 日志输出正常
- [ ] 指标记录正确

---

#### L3: 检查点恢复

```bash
python scripts/reproctl.py run-short-loop --level L3
```

**检查项**:
- [ ] 检查点保存成功
- [ ] 检查点加载成功
- [ ] 恢复后训练一致
- [ ] 无状态丢失

---

### Phase 3: 奇偶校验 (Gate 3)

#### 目标
验证优化和标准实现的一致性。

#### 检查项
- [ ] AMP/fp16 与 fp32 奇偶性
- [ ] DDP 与单 GPU 奇偶性
- [ ] 不同 batch size 奇偶性

#### 证据
- Parity 测试日志
- 指标对比表

---

### Phase 4: 完整训练 (Gate 4)

#### 目标
运行完整训练并达到目标指标。

#### 检查项
- [ ] 训练完成
- [ ] 最终指标达标
- [ ] 训练日志完整
- [ ] 环境快照已保存

#### 证据
- 训练日志
- 最终检查点
- 环境文件

---

### Phase 5: 证据链 (Gate 5)

#### 目标
生成完整的可审计证据链。

#### 检查项
- [ ] 原始指标文件存在
- [ ] 指标可重算
- [ ] 原则校验通过
- [ ] 决策日志完整

#### 证据
- `metrics.json`
- `evidence_chain.json`
- `DECISION_LOG.md`

## 指标验收标准

### 严格模式 (strict_repro)

| 指标类型 | 容差 |
|----------|------|
| 主要指标 | ±0.5 pp |
| 次要指标 | ±1.0 pp |
| 效率指标 | ±10% |

### 优化模式 (optimized_repro_safe)

| 指标类型 | 容差 |
|----------|------|
| 主要指标 | ±0.5 pp |
| 次要指标 | ±1.0 pp |
| 效率指标 | ±10% |

### 实验模式 (experimental_fast)

| 指标类型 | 容差 |
|----------|------|
| 主要指标 | ±2.0 pp |
| 次要指标 | ±5.0 pp |
| 效率指标 | ±20% |

## 失败处理

### 可恢复失败

以下情况可以重试：
- 网络超时
- 资源暂时不可用
- 进程崩溃（无 corruption）

### 不可恢复失败

以下情况需要人工决策：
- 硬件不兼容
- 数据集不可用
- 代码有 bug
- 指标严重偏离

---

## 决策日志

每个关键决策必须记录到 `DECISION_LOG.md`：

```
| D001 | 2024-01-01T00:00:00+00:00 | agent | P4_training | task-001 | budget_change | 50h → 100h | 超时后继续 | links |
```

**必须记录的决策**:
- 模式切换
- 预算变更
- 超时延长
- 覆盖检查点
- 报告结果

---

## 验收报告

复现完成后生成报告：

```bash
python scripts/reproctl.py report
```

报告包含：
- 论文信息
- 复现阶段状态
- 最终指标
- 与论文对比
- 偏差分析
- 证据链摘要
